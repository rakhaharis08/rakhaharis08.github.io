# Starship Cockpit Interior

Original, game-ready sci-fi cockpit inspired by the requested wide-canopy spaceflight composition. It is not a copy of the reference image.

## Files

- `starship_cockpit.obj` — grouped cockpit scene with hard surface geometry
- `starship_cockpit.mtl` — dark metal, canopy glass, cyan displays, amber HUD, indicators

## Included geometry

- wide three-pane canopy with structural frame
- central flight console, side consoles, controls and displays
- pilot seat, articulated armrests and floor rails
- emissive cyan / amber HUD geometry
- lower sidewalls, piping, ceiling, rear bulkhead and detailed floor plating

## Technical information

- 2,252 vertices
- 3,792 triangles
- world orientation: forward **+Z**, up **+Y**
- unit scale: approximately metres

Import the OBJ and MTL together. For a production asset, use the grouped OBJ names to create LODs and bake AO/normal maps after choosing the target engine's texture resolution.
